# Changelog

## 0.3.1 - 2026-11-22

### What's New

- Install the audit command from npm, GitHub Packages, Homebrew or Scoop, or download a portable package for macOS, Linux and Windows.
- Check LLM endpoints with 26 probes covering streaming, tool calls, structured answers, prompt isolation, context recall and fingerprint evidence.
- Run the same checks online at [LMSpeed](https://lmspeed.net/audit), with links to individual tools and shareable reports.

### Improvements

- Installed packages include both English and Chinese instructions and the preview image.
- Downloads include SHA-256 checksums and the required third-party notices.
