# История изменений

[English](./CHANGELOG.md) · [简体中文](./CHANGELOG.zh-CN.md) · [Русский](./CHANGELOG.ru.md)

## 0.3.3 - 2026-11-22

### Улучшения

- Проект перенесён в [lmspeed/audit](https://github.com/lmspeed/audit); инструкции установки и ссылки для сообщений об ошибках обновлены.
- npm и GitHub Packages предоставляют команду и SDK под единым именем `@lmspeed/audit`.

## 0.3.2 - 2026-11-22

### Улучшения

- Справка CLI теперь содержит прямые ссылки на онлайн-аудит и отчёты LMSpeed, которыми можно поделиться.

## 0.3.1 - 2026-11-22

### Новые возможности

- Установка команды аудита из npm, GitHub Packages, Homebrew и Scoop, а также переносимые архивы для macOS, Linux и Windows.
- 26 проверок LLM API: потоковые ответы, инструменты, структурированный вывод, изоляция инструкций, воспроизведение контекста и данные отпечатков.
- Те же проверки доступны онлайн на [LMSpeed](https://lmspeed.net/ru/audit), со ссылками на отдельные инструменты и отчёты для совместного доступа.

### Улучшения

- Установочные пакеты включают английское и китайское руководства и изображение предпросмотра.
- Загрузки снабжены SHA-256 и необходимыми уведомлениями сторонних лицензий.
