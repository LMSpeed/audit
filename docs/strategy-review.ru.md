# Стратегия обнаружения и границы выводов

[English](./strategy-review.md) · [简体中文](./strategy-review.zh-CN.md) · [Русский](./strategy-review.ru.md)

Документ описывает границы проверок, статистические меры и ограничения свидетельств `@lmspeed/audit` (`0.3.0`). Поддерживаемые сетевые контракты следуют открытым спецификациям WHATWG Server-Sent Events, OpenAI Chat Completions и Responses API, Anthropic Messages API.

Проверки возможностей используют настоящие структуры вызова инструментов, отрицательные контроли с запрещёнными инструментами, строгие схемы и сгенерированные медиа. Инструменты не выполняются. Проверки контекста используют случайные факты и повторное подтверждение пропусков. Условная инъекция оценивается на сбалансированных обычных и чувствительных задачах; сам отказ не является находкой.

Проверки качества измеряют небольшую нагрузку. Парные сравнения отделяют ошибки получения данных от ответов; необязательные оценки судьи имеют вспомогательный характер. Для поведенческих распределений нужны свежая совместимая калибровка, независимо собранные отложенные выборки, внешние отрицательные источники, абсолютное соответствие и разделимость. Недостаток свидетельств требует воздержаться от вывода.

Данные MIT-компонента токенизатора служат только вспомогательным свидетельством. Отдельно настраиваемый локальный числовой классификатор ранжирует закрытый набор кандидатов и не подтверждает подлинность модели вне этого набора. Сторонние эталонные данные моделей здесь не распространяются.

Самоописание модели, ID ответа, признаки в заголовках и задержка не устанавливают настоящую исходную модель. Ошибки, повреждённые потоки и неудачные случайные задачи отражают наблюдаемые контракты, а не причину нарушения. Чистый отчёт относится только к выбранной нагрузке и не является сертификатом безопасности.

HTTP fake-серверы проверяются через настоящие сокеты, включая ошибки. Независимая проверка их контрактов с авторизованными первичными провайдерами не проводилась. Автоматические тесты подтверждают реализацию контрактов, а не измеренную точность идентификации моделей.
