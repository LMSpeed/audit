# 检测验收场景

[English](./acceptance.md) · [简体中文](./acceptance.zh-CN.md) · [Русский](./acceptance.ru.md)

自动化场景通过真实回环 HTTP 服务调用公开审计入口。该服务实现文档所述的协议行为，不构成真实线上模型准确率的证据。经过独立鉴权的一手服务商契约及模型识别准确率仍未验证。

- 已声明工具并要求强制调用时，用户审计工具契约，应将错误工具名、无效参数以及禁用工具后仍返回调用判为发现。工具永不执行。
- 已声明严格 JSON Schema 时，用户审计结构化输出，应将代码围栏、类型错误、缺失字段和额外字段判为契约失败。
- 图像或 PDF 的随机答案未出现在提示词中时，用户启用该能力，应发送真实媒体字节，且只有正确识别答案才通过。
- 随机事实分布在不同上下文位置及长度时，用户审计召回，应分别检查每个位置，且不将召回失败归因于中转截断。
- 对相同确定性请求分别使用流式与非流式模式时，用户比较结果，应区分模型、协议封装、用量差异与内容变化。
- 响应包含缓存输入用量时，用户检查实报输入，应为 Messages 累加缓存读取与写入，Chat 不重复计数；未知或无效计数不能当成零。
- 响应为空但有明确拒绝标记，或意外返回 SSE 时，用户审计端点，应分类记录结果，不自动切换协议、重试或将其当普通答案计分。
- 已有确定性数学、逻辑、格式、召回与代码题时，用户审计质量，应记录每个答案及有界汇总，不推断模型身份。
- 已配置可信参照端点时，用户比较质量，目标与参照应使用相同任务和参数；采集故障不计入答案分数，裁判模型须显式配置。
- 已在独立训练和验证批次采集新鲜基线时，用户请求身份相关证据，应将匹配分布与其他参照源区分；过期、不兼容、未校准、不完整或拟合不足的样本应拒判。
- 参考库没有当前模型的可用数据时，指纹检测应在发送模型请求前跳过，保留具体原因，不判通过或风险。数字指纹只使用对应模型的样本，分词器指纹只使用已知映射；其他版本及未公开的分词器不能代替缺失数据。
- 已有平衡的普通与敏感提示词对照时，用户检查条件注入，只有可复现的秘密披露／重定向信号增量才应判为发现；拒绝或合理任务差异本身不是注入证据。
- 已设置请求数、输入、输出或时长限额时，任何新检测器的目标、参照和裁判调用都应共享该预算，传播取消信号并脱敏凭据。
- LMSpeed 选择新检测器时，审计进度、持久化事实与最终报告应通过与独立调用者相同的引擎包含该检测器。
- 已正确召回 Markdown 代码块中的事实时，审计召回应避免因格式判为事实缺失；真实缺失标记在复核后仍应失败。
- 可见文本一致但推理 Token 数不同时，比较流式与非流式计数应扣除明确报告的推理部分；缺少推理细分时应标记为证据不足，避免错误计费发现。

## 核心边界与流式契约

- 系统指令要求返回新生成的确认值、用户要求另一个答案时，精确返回才通过，不匹配属于弱置信度的系统优先级发现。
- 已生成随机受保护值时，通过直接、JSON、Base64 请求导致原文或编码泄露，即使同时出现拒绝措辞，也构成该受控泄露的强证据；不能据此推断未知中转提示词。
- 已生成随机包名字符串时，要求模型原样复制，应记录改动且不执行任何命令。
- 端点拒绝畸形 JSON 时，应报告敏感配置赋值并省略值；请求被接受或被鉴权／限流拦截时仍为证据不足。
- 检查 SSE 终结、模型一致与实报计数时，畸形载荷、缺失终结事件、模型变化和计数倒退应判为发现；只有注释／ping 的流为证据不足；未知的未来 Anthropic 事件类型本身不代表损坏。
- 响应头含多个渠道命名空间时，冲突线索应标记为含糊；通用 CDN 头与响应 ID 格式不识别渠道。
- 成功完成五次请求时，延迟报告应提供描述性统计，不沿用稳定／双峰／路由阈值。
- 请求失败、取消或耗尽预算后，剩余检测的证据缺失不能变成通过，也不能经进度／报告回调泄露凭据。

## 文档交付

- 用户从真实可发布压缩包全新安装时，应能打开英文、简中和俄文 README，且其中的本地文档与预览图片链接均可访问。
- 用户解压便携包时，无需获取源码即可阅读相同的三语指南、验收场景、证据边界、发布说明及更新日志。
