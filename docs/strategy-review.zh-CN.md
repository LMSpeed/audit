# 检测策略与证据限制

[English](./strategy-review.md) · [简体中文](./strategy-review.zh-CN.md) · [Русский](./strategy-review.ru.md)

本文概述 `@lmspeed/audit`（`0.3.0`）的检测边界、统计控制与证据限制。支持的传输契约遵循公开的 WHATWG Server-Sent Events、OpenAI Chat Completions 与 Responses API、Anthropic Messages API 规范。

能力检测使用真实工具调用封装、禁用工具的负对照、严格模式 Schema 及动态生成的媒体；全程不执行工具。上下文检测使用随机事实并复核缺失结果。条件注入检测比较平衡的普通／敏感任务对照；拒绝本身不构成发现。

质量检测只测量小规模负载。成对比较将采集故障与答案区分；可选裁判意见仅作辅助。行为分布检测要求新鲜且兼容的校准、独立采集的留出样本、外部负样本源、绝对拟合与分离度。证据不足必须拒判。

MIT 分词器证据只作辅助。另行配置的离线数字评分器只在封闭候选集合内排序，不能验证未列入集合的模型身份。本仓库不分发第三方模型参考数据。

模型自述、响应 ID、响应头线索与延迟不能识别真实上游模型。错误响应、畸形流与随机挑战失败报告的是观测到的契约问题，不推断原因。无发现的报告仅覆盖所选负载，不是安全认证。

HTTP fake 通过真实 socket 运行，包含失败场景，但尚未与经过鉴权的一手服务商进行独立契约验证。自动化测试验证实现契约，不验证实测模型识别准确率。
